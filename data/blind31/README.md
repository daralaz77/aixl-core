# blind31: paired test of one comparator rule on 120 fresh pairs (2026-11-16)
Three fresh authors (Opus W, Sonnet X, Haiku Y) wrote 120 pairs in the ten in-vocabulary constructs, with `word_order_voice` over-sampled (39 pairs, at least 6 per author active-versus-passive). The OLD comparator (git tag v0.7.1) and the NEW one (commit 4269a66 on the working branch `voice-passive-no-modal`: a closed-shape rule proving a regular 'by' passive equal to its active sentence) were run on the SAME pairs, with two blind Claude judges. Pre-registration `PREREG.md` (hash in `PREREG.sha256`); one run `RESULT_run1.txt`.
Result in one line: no false accept for either version (0 of 63), no harm elsewhere, but the pre-registered recall rule (+5 proven equivalents in the target construct) does NOT hold: +1 (5 to 6 of 20). The rule is therefore NOT merged; this directory holds the evidence only.
`CODE_FREEZE.json` hashes the code of commit 4269a66 (NEW) and of v0.7.1 (OLD); the NEW code is not part of this tree, by design. To rerun the evaluator, check out that commit (or apply `voice_rule_NOT_MERGED.patch` shipped with the round), extract the old code with `git archive v0.7.1 aixl | tar -x -C data/blind31/oldcode`; the evaluator refuses a second run because RESULT_run1.txt exists.
