# blind30: paired test of two comparator rules on 120 fresh pairs (2026-11-11)
New authors (Opus T, Sonnet U, Haiku V) wrote 120 pairs in the ten in-vocabulary constructs, with `word_order_voice` and `quantifier_all_each_any` deliberately over-sampled (24 pairs each). The OLD comparator (git tag v0.7.0) and the NEW one (a universal-quantifier rule and a passive-with-modal rule) were run on the SAME pairs, with two blind Claude judges. Pre-registration `PREREG.md`; one run `RESULT_run1.txt`.
Result in one line: no false accept for either version (0 of 60), no harm elsewhere, but the pre-registered recall rule (+5 proven equivalents in the targeted constructs) does NOT hold: +2 (4 to 6 of 26), both from the quantifier rule. The passive rule fired on no fresh pair and was REVERTED afterwards; the quantifier rule was kept (so `CODE_FREEZE.json` for the NEW code no longer matches the repository by design: the code at the time of the run had the passive rule too).
To rerun the evaluator, extract the old code with `git archive v0.7.0 aixl | tar -x -C data/blind30/oldcode` (or set AIXL_OLD_CODE); it refuses a second run because RESULT_run1.txt exists. The set is SPENT.
