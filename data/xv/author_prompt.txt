TASK: write 100 pairs of short instructions (one sentence, sometimes two clauses) for an AI agent: 50 labelled EQUIVALENT and 50 labelled NOT_EQUIVALENT. Spanish and English about equally (about 40% Spanish-only, 40% English-only, 20% cross-lingual, including some Portuguese). Be as diverse as you can in phrasing, verbs (including uncommon synonyms), sentence structure and topics: imperatives, polite requests, infinitives, passive/obligation forms, conditional clauses, permission/prohibition statements, numbers in digits or words, relative and absolute dates, date ranges, limits, thresholds, formats, languages, priorities, recipients and named entities (company names), references (#ids). Do not repeat sentence skeletons.

LABEL RULE. EQUIVALENT: a competent agent asked to do A or B would be doing exactly the same task: same action(s), same target data/entities, same time period, same quantities/numbers, same constraints (limits, thresholds, target language, output format, priority), same conditions, same references (#ids) and names, same negations/prohibitions/permissions, same order of steps. NOT_EQUIVALENT: at least one of those elements differs. No trivial or duplicate pairs.

VOCABULARY (stay inside it): Actions: analyze/examine/study; compare; find/locate/detect; create; delete/remove; check/verify/validate; translate; generate/write; calculate/compute; search; retrieve/get/fetch; execute/run; update/modify; enable/disable; send; include/exclude; allow/forbid. Data: sales, customers, users, data, datasets, images, audio, video. Entities: person, company, product, report, document, result, anomaly, event. Time: quarters, months with year, ISO dates, years, today/yesterday/tomorrow/this week/last month. Quantities: "100 records/registros". Modifiers: confidence thresholds, priority (urgent/high), limit (max/top N), output format (JSON, CSV, PDF, table, Markdown), target language. References like #77. OUTPUT: ONE code block containing exactly 100 lines, each a JSON object on a single line: {"id":"<PREFIX>-001","a":"...","b":"...","label":"EQUIVALENT" or "NOT_EQUIVALENT","category":"<one of PARAPHRASE, NEGATION, QUANTITY, TIME, CONSTRAINT, CONDITION, REFERENCE, ACTION, TARGET, OUTPUT, ORDER>","differs_in":["<dimension names; empty list for EQUIVALENT>"]}.
