# ADR-003: Normalization uses closed lexicons, never fuzzy similarity
Status: Accepted

**Problem.** Treating similar words as synonyms silently merges different instructions (§26–27).

**Decision.** `SemanticNormalizer` and the translator map only expressions declared in lexicons/`action_groups`. Context-sensitive phrases keep an explicit attribute (e.g. aggregate). Out-of-lexicon words are not guessed.

**Alternatives.** Embedding similarity; WordNet-style synonym expansion.

**Reasoning.** A wrong merge is invisible; a missed synonym is visible as a difference and can be fixed by adding a lexicon entry plus a test.

**Consequences.** Coverage grows only by evidence from blind sets; unknown nouns are reported, not understood (ADR-008).

**Compatibility.** Vocabulary additions are PATCH/MINOR (VERSIONING_POLICY.md); fingerprints may change.
