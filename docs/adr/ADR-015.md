# ADR-015: Fingerprints are over the canonical form, version-bound, and conservative
Status: Accepted

**Problem.** A stable hash of meaning is useful for dedup and audit but must not equate different meanings (§32–34).

**Decision.** `fingerprint_graph` = truncated SHA-256 of sorted-key JSON of `canonical()`; any canonical difference (including bindings) changes it; relative time uses an explicit `today`.

**Alternatives.** Hash the text; hash a subset of dimensions; locality-sensitive hash.

**Reasoning.** Exact hashing cannot create false equivalence; extra differences are the safe error.

**Consequences.** Not stable across versions or lexicon changes; equal fingerprints prove equal canonical form, not equal intent.

**Compatibility.** Store `aixl.__version__` and `today` with persisted fingerprints (VERSIONING_POLICY.md).
