# ADR-010: Action–argument binding: K:BIND, unknown when absent, positional only when reliable
Status: Accepted

**Problem.** A flat frame cannot tell 'delete users, analyze reports' from the swapped sentence (LIMITATIONS #3).

**Decision.** Canonical dimension `bindings` = `ACTION>ARG` pairs for 2+ action texts, serialized as `K:BIND=ACTION>ARG` (existing K atom, parser untouched, card unchanged). Arguments: references, entities, data. Compared per argument as sets of actions: empty side = unknown (skipped), subset = compatible, disjoint = difference (CRITICAL if destructive). Not produced for passives or step-order cues. Output formats and anaphoric dependencies are NOT bound (graph edges only).

**Alternatives.** Full binding in AIXL with a new card; canonical-only (no wire form); bind everything including time and output.

**Reasoning.** Evidence: binding output and dependencies first produced 19 false NOT_EQUIVALENT on 1400 labelled pairs; after the restrictions 0 verdict changes. An encoder without BIND (an LLM with the frozen card) must stay comparable, hence unknown-when-absent.

**Consequences.** Swaps are undetected on the LLM route, in passive/ordered clauses, and for output/time. Fingerprints include bindings, so equivalent paraphrases may hash differently (safe direction).

**Compatibility.** Adds a dimension and a constraint key; old lines decode with empty bindings; stored fingerprints of multi-action texts change (see SEMANTIC_CHANGELOG.md).
