# ADR-005: Confidence is extraction metadata, never evidence
Status: Accepted

**Problem.** A number like 0.9 can be mistaken for the truth of a statement (§69).

**Decision.** `SemanticObject.confidence` is extraction confidence only; it is excluded from `canonical()`, comparison and fingerprint; the validator rejects values outside [0,1].

**Alternatives.** Weight differences by confidence; drop low-confidence nodes.

**Reasoning.** Either alternative lets a score change meaning silently.

**Consequences.** Low-confidence extractions still count fully in comparisons.

**Compatibility.** None; field already existed.
