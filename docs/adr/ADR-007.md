# ADR-007: Severity is context-sensitive for destructive and external actions
Status: Accepted

**Problem.** Dropping a recipient, scope or safeguard is harmless on a read but dangerous on DELETE/SEND (§64).

**Decision.** `_severity` escalates changed/removed references, entities, data, conditions, constraints (and bindings, ADR-010) to CRITICAL when a destructive action in `config.destructive_actions` is involved. 'Added' (narrowing) keeps base severity.

**Alternatives.** Flat per-dimension severity; per-domain policy tables.

**Reasoning.** Found by the adversarial suite (§39): 11 silent failures, all fixed; 57/57 flagged, 0/31 false alarms.

**Consequences.** More CRITICAL results on destructive actions by design.

**Compatibility.** Changing a default severity is a MAJOR-type change (VERSIONING_POLICY.md); config keys are stable.
