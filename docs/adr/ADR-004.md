# ADR-004: LLMs propose, the Core validates and decides
Status: Accepted

**Problem.** Rules plateau around 76–88 % on unseen phrasing; an LLM reads better but is non-deterministic and provider-specific (§41–42).

**Decision.** `aixl/translators/auto.py` chooses a route via `AIXL_TRANSLATOR_MODE`: rule_based (default), llm/auto (LLM emits one AIXL line, decoded by the unmodified codec; falls back to rules on any failure), local (offline model). The Core canonicalizes and compares whatever graph results; model-proposed nodes are marked `MODEL_DERIVED` (ADR-011).

**Alternatives.** LLM-only translator; rules-only forever; fine-tune and ship a model as the only route.

**Reasoning.** Determinism and a zero-dependency default are preserved; the LLM route is opt-in with measured 93.5–96.5 % cross-vendor accuracy. Local route measured F1 0.69, so it is not the default.

**Consequences.** Behaviour depends on the route; fingerprints from different routes can differ for the same text.

**Compatibility.** Default unchanged since before the LLM route existed.
