# ADR-020 — LLM extraction wrapper with abstention (`aixl/atoms/llm_extract.py`) — STATUS: ACCEPTED 2026-10-04 (one test set, n = 150)

## Decision
ADR-019 found that two strong LLMs agree on the whole atom graph only ~35 % of the time on unseen text, so no single extraction can be trusted as *the* graph. Following ADR-004/ADR-018 (the model proposes, the core validates and decides; the core calls no model), the wrapper:
1. builds a self-contained prompt (`build_prompt`: registry digest + the full annotation guide + the texts; versioned by `prompt_id()`);
2. parses and validates every response (`parse_response`: tolerant of fences, reports invalid/missing ids, endpoint-type/TIME-grammar/unknown-key errors, canonicalizes `x:` lemmas);
3. runs **k ≥ 2 independent calls** and **abstains unless they agree** (`decide`): policy `exact` (identical graphs) or `core` (modality/negation, quantity, time, scope and limits identical; auxiliary links may differ). One call can never be accepted; an invalid call forces ABSTAIN with the candidates attached.

## Evidence (docs/ATOMS_WRAPPER_EVIDENCE.md, reproducible from stored responses; blind3 = 150 unseen texts; calls = Sonnet + Opus produced from `build_prompt`; references = the earlier independent annotations of the same texts)
* Format reliability: 300/300 responses parsed and validated (0 invalid, 0 missing).
* Single calls vs references: Sonnet exact 0.35 / core F1 0.81; Opus exact 0.42 / core F1 0.86.
* `exact` policy: accepts 35 % (53/150); accepted graphs agree with the references at exact 0.63, F1 0.92, core F1 0.93 (81 % identical to at least one reference); the abstained 97 score exact 0.20, core F1 0.76. The agreement filter separates reliable from unreliable extractions.
* `core` policy: accepts 67 % (100/150); accepted core F1 0.925 against 0.672 on the abstained; 47 of those accepted differ only in auxiliary links.
## Limits
n = 150 on one set (binomial noise ≈ ±10 pts on the 53-case subset); the references are themselves noisy (their mutual exact agreement is 0.36), so measured agreement understates true accuracy and the lift is a lower bound only in that sense; the three models share a family; no human adjudication; abstention means "ask a person or a third call", not "wrong". It does not change the arbiter baseline (ADR-018) for free-text equivalence.
