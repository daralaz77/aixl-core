# ADR-013: Ambiguity with context never picks a candidate
Status: Accepted

**Problem.** 'Envía el informe a Juan' with two Juans must not silently choose one (§24, §35, §91).

**Decision.** `detect_ambiguity(text, context={'entities': […]})`: several matching entities => blocking AMBIGUOUS_REFERENCE with candidates, affected nodes and required context; one => RESOLVED_REFERENCE note (provenance EXTERNAL_CONTEXT, graph not mutated); none => UNKNOWN_REFERENCE note. Name tokens that share a candidate form one mention.

**Alternatives.** Resolve to the best match; mutate the graph with the resolved entity; require context.

**Reasoning.** Resolution is a decision the caller owns; UNKNOWN and AMBIGUOUS are different states.

**Consequences.** Name-token matching only; no role/gender/recency cues; pronouns are not resolved against the context.

**Compatibility.** Optional parameter; without context behaviour is unchanged.
