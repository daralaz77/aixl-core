# ADR-011: Provenance is node metadata outside the canonical form
Status: Accepted

**Problem.** Inferred or model-proposed content must be distinguishable from stated content (§68).

**Decision.** `SemanticObject.provenance`: EXPLICIT (default), INFERRED (derived INTENT/GOAL), MODEL_DERIVED (LLM/local routes via `mark_model_derived`). RESOLVED and EXTERNAL_CONTEXT are valid but produced only in ambiguity notes.

**Alternatives.** Put provenance in canonical; separate graphs per origin.

**Reasoning.** Keeping it out of `canonical()` means origin never changes equivalence or fingerprints; the validator still checks the value.

**Consequences.** Not yet used by any engine to weigh or filter.

**Compatibility.** Additive field with default; JSON without it loads as EXPLICIT.
