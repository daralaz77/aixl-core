# ADR-014: The Core represents what should be done and never executes it
Status: Accepted

**Problem.** A semantic layer that also acts becomes a confused deputy (§75–76).

**Decision.** No module in `aixl/core` or `aixl/translators` performs I/O beyond optional LLM/Ollama calls for translation; protocol adapters (MCP, A2A) expose translate/compare/negotiate only. A property test checks the graph module does not import process-execution APIs.

**Alternatives.** Optional executor plugin; built-in firewall.

**Reasoning.** Execution belongs to a later layer with its own trust model.

**Consequences.** Consumers must enforce policy themselves; `explain()` is groundwork, not enforcement.

**Compatibility.** No change.
