# ADR-008: Unknown words are reported, never silently ignored
Status: Accepted

**Problem.** Out-of-lexicon text yields an empty graph that can compare 'equivalent' to another empty graph (LIMITATIONS #2).

**Decision.** `UNRECOGNIZED_TERMS` warning for object nouns outside the lexicon and a BLOCKING `NO_ACTION_RECOGNIZED` warning when no action is found; `validate()` reports both as SEMANTIC_LOSS. The verdict itself is unchanged.

**Alternatives.** Raise an error; extend the lexicon indefinitely; change the verdict to INSUFFICIENT_CONTEXT.

**Reasoning.** A warning adds transparency without changing measured accuracy; the 5x100 ratchet went 94.0 % → 99.4 % with PT lexicons plus this warning.

**Consequences.** Callers must read `warnings`; 'equivalent' with a blocking warning means 'cannot verify'.

**Compatibility.** Additive key; appears only when non-empty.
