# ADR-009: 'Most recent' is a constraint, not a time period
Status: Accepted

**Problem.** 'el informe más reciente' selects which object; the demo of §92 lost it, so searching for the latest report compared EQUIVALENT to searching for any report.

**Decision.** `ORDER=MOST_RECENT` / `ORDER=OLDEST` constraints (ES/EN/PT; also singular 'último <noun>'). 'últimos 5' stays `SELECT`, and 'último mes/trimestre' stays a time token.

**Alternatives.** Model as a TIME node; as a MODIFIER; leave to the LLM.

**Reasoning.** It is a selection criterion on the object, so it belongs with constraints and is compared there. Measuring against the blind sets caught that 'último documento' (A043, labelled equivalent) needed the same mapping.

**Consequences.** The ambiguity detector's VAGUE_TIME on 'reciente' is unchanged.

**Compatibility.** New constraint key (MINOR); old AIXL lines without it are unchanged.
