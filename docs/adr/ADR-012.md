# ADR-012: validate() and round_trip() are pure, structured, and honest about scope
Status: Accepted

**Problem.** The Core needs a gate (§43) and a fidelity measure (§38) without executing or mutating anything (§75).

**Decision.** `validate` returns VALID / INVALID / VALID_WITH_WARNINGS with issues (code, severity, where, message) using the §44 error names; errors only for structural or contradictory graphs, loss and ambiguity are warnings. `round_trip` encodes to AIXL, decodes, compares; fidelity = mean per-dimension agreement; a codec failure is a result (fidelity 0, error text), not an exception.

**Alternatives.** Bare booleans; raising on invalid; scoring fidelity against the original text.

**Reasoning.** Structured output is auditable and does not hide partial loss. Fidelity against the text would need ground truth the Core does not have.

**Consequences.** Fidelity measures encoding loss only; extraction errors are invisible to it. Validator warns about the 'no action recognised' case so empty graphs are not read as valid meaning.

**Compatibility.** New API functions (MINOR).
