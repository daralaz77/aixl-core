# ADR-002: Equivalence is exact on the canonical form; similarity is only diagnostic
Status: Accepted

**Problem.** A single similarity score hides which meaning changed and invites a threshold nobody can justify (§31).

**Decision.** `compare_canonical` declares EQUIVALENT only if no non-derived dimension differs. `similarity`/`drift` are weighted by `data/config.json` and reported next to concrete `Difference` records (field, source, target, kind, severity).

**Alternatives.** Threshold on a cosine/weighted score; majority vote across dimensions.

**Reasoning.** Exactness keeps negation, target and quantity changes from being averaged away. Severity is per difference, configurable, not a verdict.

**Consequences.** Paraphrases the lexicon does not cover become false NOT_EQUIVALENT (recall 57–72 % on blind sets, precision 92–100 %). That is the deliberate error direction.

**Compatibility.** Result shapes only gain keys (VERSIONING_POLICY.md).
