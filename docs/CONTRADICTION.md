# Contradiction
`detect_contradiction_graphs(a, b)` (`aixl/core/contradiction.py`) requires (1) the same object (`overlapping`: each identifier kind both sides state must intersect) and (2) a demonstrable opposition: request vs prohibition of the same action, ALLOW vs FORBID, ENABLE/DISABLE, INCLUDE/EXCLUDE, PUBLIC/PRIVATE, BEFORE/AFTER, step order. Different texts are never a contradiction by themselves.
Not covered: implicit contradictions, contradictions inside one text, MIN>MAX numeric conflicts.
