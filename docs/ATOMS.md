# AIXL 0.4 — Semantic Atom layer (`aixl/atoms/`)

Status 2026-10-04: **experimental; usable as a verifiable interchange format and as a measuring instrument; NOT a general extractor of meaning from free text.** Read [ATOMS_EVIDENCE.md](ATOMS_EVIDENCE.md) (every number, regenerated by `benchmarks/atoms_report.py`) and [adr/ADR-019.md](adr/ADR-019.md) before claiming anything.

## What it is
`text → AtomGraph (atoms + typed relations) → AIXL wire message → AtomGraph → meaning`. The graph, not the sentence, is what is transported. Identity is a **concept id** (`ACT.SUMMARIZE`), never a word; anything outside the registry is an explicit extension `x:<lemma>` that a receiver may refuse (no silent mapping to a nearby concept).

| module | role |
|---|---|
| `registry.py` | versioned closed registry: 11 atom types, 6 modalities, ~25 relations with **enforced endpoint types**, ~95 concepts (actions/entities/properties/formats), units |
| `schema.py` | `Atom`, `AtomGraph`; `validate()` (types, endpoints, TIME grammar, unknown keys); **id-independent canonical form** (Weisfeiler–Lehman) and `fingerprint()`; `unrepresented` = explicit loss marker, part of the fingerprint |
| `wire.py` | line-oriented transport-independent serialization; `decode(encode(g))` keeps the fingerprint; strict decode never guesses |
| `firewall.py` | `Profile` (HELLO), `common_profile` (intersection), `receive()` (malformed / unsupported concept / extension policy / **SEMANTIC_INTEGRITY_FAILURE**), `align()` (EXACT/CLOSE/BROADER/NARROWER/RELATED/INCOMPATIBLE/UNKNOWN, never auto-promotes), `diff()` (atom-level differences) |
| `fidelity.py` | ATOM INTEROPERABILITY FIDELITY: precision/recall/F1 per dimension (identity, value, relation, scope, constraint, polarity, temporal, quantitative, reference) + `core` (safety-critical subset) + exact-graph rate |
| `extract.py` | deterministic ES/EN/PT extractor for a **controlled domain**; fail-closed: whatever it cannot place goes to `graph.unrepresented` |

Annotation guide for humans/LLMs: [ATOM_MODEL.md](ATOM_MODEL.md) (v0.2 → v0.3 → v0.4, later sections win). Registry reference (generated): [ATOMS_REGISTRY.md](ATOMS_REGISTRY.md).

## Use
```python
from aixl.atoms.extract import extract
from aixl.atoms.wire import encode
from aixl.atoms.firewall import Profile, receive, diff
g = extract("Resume el informe en máximo 150 palabras.")     # g.complete tells whether anything was left unrepresented
msg = encode(g)                                               # AIXL 0.4 wire message
v = receive(msg, Profile("receiver"))                         # v.accepted, v.reasons, v.unsupported
print(diff(extract("Usa fuentes oficiales."), extract("No uses fuentes oficiales.")))   # exactly one change: modality DO -> DONT
```
CLI: `python cli.py atoms-extract|atoms-wire|atoms-receive|atoms-diff ...`.
For natural text use the wrapper `aixl.atoms.llm_extract` (ADR-020): `extract_llm(text, [call_a, call_b], policy='core')` → ACCEPT only when two independent calls agree, otherwise ABSTAIN with the candidates (you supply the callables; the core calls no model). Equivalent manual route: produce the graph with a schema-constrained LLM (give it ATOM_MODEL.md + the registry) and pass it through `AtomGraph.from_dict(...).validate()` and `firewall.receive`: the core validates and canonicalizes, it calls no model (same stance as ADR-004/ADR-018).

## What is measured (summary; table in ATOMS_EVIDENCE.md)
* Two strong LLMs (Sonnet, Opus) annotating the same unseen natural instruction agree on the whole graph only **~35 %** of the time (F1 ≈ 83 %, core F1 ≈ 83–86 %). Three schema rounds (v0.2→v0.4) moved that 32.7 → 35.3 → 36.0 % on fresh texts: within noise (±4 pts). Natural language admits several valid decompositions; adding relations does not make the graph unique.
* On the author's own dev set the same comparison gives 93–98 % and the rule extractor 98 % — **tuning artefacts, not performance**. On three unseen sets the rule extractor scores F1 0.27–0.37 and declares **0/450 complete** (zero silent errors, zero coverage).
* Transport is not the loss: through AIXL with a different model writing text in the middle and a third re-extracting, F1 is 0.93 (core 0.97), equal to the noise floor between two independent readers of the original (40 cases, two directions, Claude models only).
* LLM wrapper with abstention (ADR-020, docs/ATOMS_WRAPPER_EVIDENCE.md): 300/300 responses valid; policy `core` accepts 67 % of 150 unseen texts with core F1 0.93 vs 0.67 on the abstained; policy `exact` accepts 35 % at exact-graph 0.63 vs 0.20 on the abstained (references noisy, n = 150, Claude models only).
